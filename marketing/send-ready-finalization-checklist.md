# Send-Ready Finalization Checklist — The High-Agency AI Worker

## Goal
Turn the structurally complete publisher packet into a truly send-ready submission package.

## Current status note
This checklist is **future external-track only**.
It is not required for the current internal development lane.

## Phase A — Author identity completion
- [ ] Replace `[Author Name]` in `marketing/author-bio-platform-sheet.md`
- [ ] Replace all `[insert]` fields with real links, counts, and credentials
- [ ] Choose final short author bio
- [ ] Choose final standard author bio
- [ ] Select 2–3 final credibility angles
- [ ] Select one final author positioning line

## Phase B — Submission choices
- [ ] Confirm final title
- [ ] Confirm final subtitle
- [ ] Confirm preferred sample chapter order
- [ ] Confirm whether packet tone should skew more commercial or more intellectual

## Phase C — Packet coherence pass
- [ ] Proposal title/subtitle matches final title sheet choice
- [ ] Submission packet index reflects final reading order
- [ ] Comparable titles fit target editor/publisher taste
- [ ] Manuscript scope note matches final intended range
- [ ] No placeholder text remains in packet docs

## Phase D — Optional formatting pass
- [ ] Convert materials into one merged document or PDF
- [ ] Normalize headings and typography across docs
- [ ] Add page breaks or separators for submission readability
- [ ] Produce filename-safe final packet names

## Send-ready definition
The packet is send-ready only when:
1. no placeholders remain,
2. author identity/platform fields are real,
3. final title/subtitle are fixed,
4. packet order is finalized,
5. and the proposal matches the rest of the submission set exactly.
